AI Prompt Library

Welcome to the AI Prompt Library, a lightweight web application designed to help you organize and store your favorite AI prompts.

To use this project, ensure you have VS Code, Git, and Docker installed and that you are logged into your Docker account.

First, open your VS Code terminal and clone the repository by typing: git clone https://github.com/angelinacarvelli/IA-Prompt-Library.git

Once the files are in your workspace, launch the application by entering: docker compose up
This will build the Docker image and start the library service.

Finally, open your web browser and navigate to localhost:8080 to access the interface.
